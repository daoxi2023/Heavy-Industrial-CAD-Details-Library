# Heavy Industrial Steel Connections - 2D CAD Details Library 📐

Welcome to the **Heavy Industrial CAD Details Library**, an open-source collection of standard 2D structural steel connection drawings (DWG, DXF, and PDF formats) for heavy industrial construction.

## 📋 Repository Contents (Coming Soon)
This library provides ready-to-use 2D drafting details for structural engineers and draftsmen, saving you time during the design and shop-drawing phases of heavy industrial projects:
* Typical Crane Runway Beam Details
* High-Capacity Column Splices
* Heavy Duty Equipment Base Frames & Anchor Plans
* Truss Node Connections & Gusset Plates
